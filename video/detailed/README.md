# Подробный обзор CAM NESTING

15 минут 17 секунд · Full HD · русская озвучка, голос 2 · субтитры.

Чтобы скачать полный MP4 на Windows:

1. Скачайте [Download_CAM_Video.cmd](https://github.com/raevka190-lang/cam-/raw/refs/heads/main/video/detailed/Download_CAM_Video.cmd).
2. Поместите файл в папку, где хотите сохранить видео, и запустите двойным щелчком.
3. Дождитесь сообщения Saved. Рядом появится CAM_NESTING_Detailed_Overview.mp4.

Скачивание требует интернета. CMD загружает 14 частей (всего около 41 МБ), объединяет их и проверяет SHA-256. Программы и настройки CAM не изменяются. Существующее видео не заменяется. Части содержат исходный MP4 без повторного сжатия.

При наличии Python можно использовать download_cam_video.py из этой папки.

В обзоре: БАЗИС, загрузка заказа и материалы, редактор векторов, методы и стили, раскрой, симуляция, редактор траекторий, вывод УП и документы, редактор постпроцессора, приложение заказа раскроя.
