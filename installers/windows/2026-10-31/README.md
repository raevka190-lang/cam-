# CAM NESTING — установщик от 31.10.2026

Включены фигурный раскрой, редактор бирок, независимый метод реза обрезка и предыдущие обновления. Python встроен. Windows 10/11, 64 бит.

1. Скачайте [Download_CAM_Setup.cmd](https://github.com/raevka190-lang/cam-/raw/refs/heads/main/installers/windows/2026-10-31/Download_CAM_Setup.cmd) в отдельную папку.
2. Запустите CMD двойным щелчком. Дождитесь всех 6 частей и сообщения READY.
3. Рядом появится **CAM_Nesting_Setup_2026-10-31.exe**. Закройте CAM и редактор ПП, затем запустите этот EXE.
4. Для обновления выберите прежнюю папку программы.

При скачивании всей папки репозитория CMD собирает установщик из локальной папки parts, без повторной загрузки. Иначе требуется интернет.

CMD только скачивает/объединяет части и проверяет SHA-256. Сам установщик запускаете вы. Существующие файлы не заменяются без проверки.

Пользовательские проекты, настройки и существующие постпроцессоры сохраняются. Проверена установка поверх старой версии, повторная установка, запуск CAM и отдельного редактора ПП, раскрой 29 дуг на одном листе и экспорт NC/бирок/отчётов.
